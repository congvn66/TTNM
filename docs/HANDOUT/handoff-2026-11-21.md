## 7. Luồng sản phẩm và nơi kiểm tra

### 7.1. Auth

    POST /api/v1/auth/register
      -> users + auth_sessions -> HttpOnly sourcelens_session cookie
    GET  /api/v1/auth/me
    POST /api/v1/auth/logout

Các endpoint phụ:

    GET    /api/v1/auth/sessions
    DELETE /api/v1/auth/sessions/{session_id}
    POST   /api/v1/auth/sessions/revoke-others
    GET    /api/v1/settings/profile
    PATCH  /api/v1/settings/profile
    GET    /api/v1/settings/preferences
    PATCH  /api/v1/settings/preferences

Token thô chỉ ở cookie; DB lưu hash. Không gửi owner_id từ frontend; backend
lấy owner từ session.

### 7.2. Session và upload PDF

    POST /api/v1/sessions
    POST /api/v1/sessions/{session_id}/documents
    GET  /api/v1/sessions/{session_id}
    GET  /api/v1/jobs/{job_id}
    GET  /api/v1/jobs/{job_id}/events

Upload kiểm tra extension/header, giới hạn 100 MiB, hash SHA-256, lưu binary ở
R2, metadata PostgreSQL, tạo extraction job. Trạng thái tài liệu:
queued -> processing -> ready|failed.

### 7.3. Extraction

    PDF -> Docling base extraction -> document-evidence-v2
        -> pages, text, tables, bbox, numeric evidence, chart regions
    QuestionPlan -> chỉ khi chart fact còn thiếu -> DePlot chart run

Docling đọc text/bảng khi base extraction. DePlot không chạy cho mọi upload;
chỉ chạy khi QuestionPlan yêu cầu chart. Mỗi số chart phải có method_label là
đọc từ nhãn hoặc ước lượng theo trục; số không chứng minh được là
ambiguous/unreadable, không tự đoán.

### 7.4. Hỏi đáp AI và worker

    POST /api/v1/sessions/{id}/messages
      -> persist user + assistant processing
      -> enqueue answer_question
    worker claim bằng lease
      -> QuestionPlan -> retrieval/evidence resolve
      -> calculator deterministic -> chart nếu cần
      -> OpenRouter structured JSON
      -> citation/quote/schema validation
      -> answer_revision + message hoàn tất

Theo dõi:

    GET  /api/v1/jobs?status=queued
    GET  /api/v1/jobs/{job_id}
    GET  /api/v1/jobs/{job_id}/events
    POST /api/v1/jobs/{job_id}/cancel
    POST /api/v1/jobs/{job_id}/retry
    GET  /api/v1/sessions/{session_id}/messages/{message_id}/trace

Phép tính tổng/hiệu/phần trăm do code thực hiện. LLM chỉ hiểu câu hỏi và
trình bày. Quote ngoài context phải fail typed, không lưu câu trả lời giả.

### 7.5. Sửa số và lịch sử

    GET  /api/v1/sessions/{sid}/documents/{did}/evidences
    GET  /api/v1/sessions/{sid}/documents/{did}/evidences/{key}/revisions
    POST /api/v1/sessions/{sid}/documents/{did}/evidences/{key}/revisions

Request sửa gửi expected_revision_id. Server lưu giá trị cũ, mới, lý do,
previous_revision_id và tạo revision mới. Revision cũ gửi lại nhận 409
EVIDENCE_REVISION_CONFLICT. Không update trực tiếp extracted_evidences.

### 7.6. CRUD thư viện

| Chức năng | Endpoint |
|---|---|
| Project list/create/rename/archive | GET/POST /api/v1/projects, PATCH/DELETE /api/v1/projects/{id} |
| Project library | GET /api/v1/projects/{id}/library |
| Folder list/create/rename/archive | GET/POST /api/v1/projects/{id}/folders, PATCH/DELETE /api/v1/folders/{id} |
| Move session | PATCH /api/v1/sessions/{id}/project |
| Rename/archive document | PATCH/DELETE /api/v1/projects/{pid}/documents/{did} hoặc session document endpoint |

Quan hệ là project (thư viện) -> chat (phiên phân tích) -> chat_documents.

## 8. Swagger và debug data flow

Mở http://127.0.0.1:8000/docs. Với endpoint cần auth, đăng nhập trước bằng
Swagger hoặc frontend để browser giữ cookie.

Mỗi request quan trọng cần kiểm tra:

1. HTTP status và response body/schema.
2. job_id, trace_id, message_id, assistant_message_id.
3. job events: queued -> claimed -> progress -> succeeded hoặc retry/fail.
4. message trace: question plan, retrieval, calculator, provider validation,
   persistence; trace không chứa raw prompt/PDF.
5. PostgreSQL record tồn tại sau reload.
6. R2 object tồn tại sau upload và không mất khi restart API.

Log backend có các event FLOW HTTP_IN, FLOW HTTP_OUT, UPLOAD_ACCEPTED,
ANSWER_PERSISTED, EXTRACTION_FINISHED. Log chỉ để chẩn đoán, không thay cho
PostgreSQL/R2.

## 9. Checklist test thủ công

### Tài khoản và owner isolation

- [ ] Tạo user A, đăng nhập, tạo session và upload PDF.
- [ ] Tạo user B, không đọc được session/document/job của A (404).
- [ ] Đăng xuất A, gọi API phải nhận 401.
- [ ] Revoke một device/session, cookie tương ứng không dùng được.

### Tài liệu và persistence

- [ ] Upload PDF hợp lệ dưới 100 MiB; tên Unicode giữ đúng UTF-8.
- [ ] Upload sai extension/header, file rỗng, file trên giới hạn; lỗi rõ.
- [ ] Reload browser/restart backend, session/document vẫn còn.
- [ ] Đổi tên session/document, reload thấy tên mới.
- [ ] Archive session/document, active API không còn trả record.
- [ ] Kiểm tra R2 object: archive hiện chưa xoá binary vĩnh viễn.

### AI và chart

- [ ] Hỏi text/bảng: không gọi DePlot.
- [ ] Hỏi câu cần biểu đồ: tạo on-demand chart extraction.
- [ ] Thiếu kỳ/đơn vị: needs_clarification.
- [ ] Mẫu số 0/sai đơn vị/thiếu số: không trả số đoán.
- [ ] Citation nhảy đúng trang và bbox scale-invariant.
- [ ] OpenRouter lỗi mạng: retry bounded, không hiện answer thành công giả.

### Revision và concurrency

- [ ] Sửa 100 -> 110, history chứa cả hai giá trị.
- [ ] Dùng revision cũ để sửa đồng thời, request sau nhận 409.
- [ ] Hỏi lại sau sửa, answer mới dùng revision mới.
- [ ] Answer cũ giữ snapshot revision cũ.
